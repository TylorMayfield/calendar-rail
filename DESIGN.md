# Visual rules

The in-page link follows the current Gmail rail: 64px row, 20px outline calendar icon, 12px label, existing text color and font. Insert immediately after the last recognized Mail/Chat/Meet row. Use an isolated shadow root; never clone a Gmail control or event handler. Original monochrome calendar app icon belongs only in the extension's own help page and listings. No Google brand assets. A visible keyboard outline, hover state, tooltip and new-tab accessible name are required. Hide labels in genuinely narrow navigation. Match the page's theme, not just the operating system preference.
